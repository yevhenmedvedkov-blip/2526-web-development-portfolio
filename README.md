# Web Development Portfolio

Welkom op mijn Web Development portfolio voor de opleiding Multimedia & Creatieve Technologie aan KdG.

In deze repository documenteer ik mijn leerproces, oefeningen, opdrachten en de vaardigheden die ik tijdens de lessen ontwikkel.

## Over mij

Ik ben een creatieve designer met een achtergrond in UX/UI Design, Product Design en Web Design.

Naast mijn designervaring heb ik een sterke interesse in front-end development en het bouwen van interactieve digitale ervaringen.

Met dit vak wil ik mijn technische kennis verder ontwikkelen en beter begrijpen hoe design en development samenkomen in een functioneel digitaal product.

## Mijn persoonlijke portfolio website

Naast de oefeningen en opdrachten voor dit vak wil ik ook mijn eigen portfolio website presenteren.

Deze website is een persoonlijk project waarin ik verschillende vaardigheden toepas die aansluiten bij de onderwerpen van Web Development.

**Wat je op mijn website kunt ontdekken:**

- **Responsive Design** – De website is geoptimaliseerd voor desktop, tablet en mobiele apparaten.
- **CSS Animations & Interactions** – Animaties en interactieve elementen maken de gebruikerservaring dynamischer.
- **Component-based Design** – De interface is opgebouwd met herbruikbare componenten.
- **SEO Basics** – De website bevat een basisstructuur voor zoekmachineoptimalisatie.
- **UX/UI Design** – De structuur, navigatie en interacties zijn ontworpen met aandacht voor gebruiksvriendelijkheid.
- **Web Development** – De website combineert visueel ontwerp met technische implementatie.

De website laat zien hoe ik designprincipes en technische vaardigheden combineer om een complete digitale ervaring te creëren.
