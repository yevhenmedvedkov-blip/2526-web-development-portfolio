# Les 01 – Web Production 101

## 1. Samenvatting

Tijdens deze introductieles hebben we kennisgemaakt met het vak Web Production en de verschillende aspecten van moderne webontwikkeling.

De les behandelde zowel de visuele als de technische kant van webproductie. Hierbij kwamen onder andere frontend development, animaties, toegankelijkheid (accessibility), SEO, performance en interactieve elementen aan bod.

Daarnaast maakten we kennis met verschillende ontwikkeltools, zoals Visual Studio Code, Node.js en Cursor.

Een belangrijk onderdeel van de les was de werking van de DOM (Document Object Model). We bekeken hoe een browser HTML omzet naar een DOM-structuur en hoe JavaScript deze structuur dynamisch kan aanpassen.

Ook hebben we kennisgemaakt met browser Developer Tools, waaronder Inspector, Console, Network en Sources. Hiermee kunnen we websites analyseren, elementen inspecteren en problemen opsporen.

## 2. Bronnen

Tijdens deze les werden verschillende tools en informatiebronnen besproken:

- [MDN Web Docs](https://developer.mozilla.org/) – documentatie over HTML, CSS en JavaScript.
- [CodePen](https://codepen.io/) – experimenteren met frontend code.
- [Smashing Magazine](https://www.smashingmagazine.com/) – inspiratie en artikelen over webontwikkeling.
- [Visual Studio Code](https://code.visualstudio.com/) – code-editor.
- [Chrome DevTools](https://developer.chrome.com/docs/devtools/) – tools voor het inspecteren en debuggen van websites.
- [Node.js](https://nodejs.org/) – JavaScript-runtime.

## 3. Oefeningen

Tijdens de les werden twee opdrachten geïntroduceerd:

**Opdracht 0.1 – Portfolio opzetten**

Het opzetten van een persoonlijk portfolio en het beschikbaar maken ervan via Canvas.

Ik heb hiervoor mijn bestaande persoonlijke portfolio website gebruikt. Deze website heb ik zelf ontworpen en ontwikkeld.

**Opdracht 0.2 – Make websites ugly again**

Het aanpassen van een bestaande website via de browser Inspector om beter te begrijpen hoe HTML-elementen en CSS-stijlen werken.


## 4. Wat ik heb geleerd

De les heeft mijn inzicht in de technische werking van websites verder uitgebreid.

Vooral het onderscheid tussen de HTML-sourcecode en de DOM-structuur is belangrijk. De HTML-sourcecode vormt de oorspronkelijke structuur, terwijl de browser hiervan een DOM-boom maakt die tijdens het gebruik dynamisch kan veranderen.

Ik heb ook mijn kennis van browser Developer Tools verder verdiept. Deze tools zijn nuttig om de structuur van een website te onderzoeken, CSS-aanpassingen te testen en technische problemen op te sporen.

Daarnaast werd duidelijk dat moderne webontwikkeling meer omvat dan alleen het visuele ontwerp. Ook toegankelijkheid, performance, SEO en interactie spelen een belangrijke rol.

## 5. Zelfreflectie

In mijn persoonlijke portfolio website heb ik verschillende onderwerpen toegepast die tijdens deze les aan bod kwamen.

Ik heb zelfstandig gewerkt aan het ontwerp en de technische realisatie van de website. Daarbij heb ik onder andere aandacht besteed aan:

- Een responsive layout voor desktop, tablet en mobiel.
- Animaties en interactieve elementen.
- Een consistente visuele structuur met herbruikbare componenten.
- Basisprincipes van SEO.
- De combinatie van UX/UI Design en frontend development.

Door mijn bestaande project te vergelijken met de onderwerpen uit deze les, kan ik beter begrijpen hoe de verschillende onderdelen van webproductie samenkomen.

Een aandachtspunt voor mij is om mijn kennis van de DOM, JavaScript en debugging verder te verdiepen en mijn technische keuzes beter te documenteren.
